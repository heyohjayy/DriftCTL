# Screenshot Checklist

This directory will hold sanitized screenshots used in the project README and setup guide.

Add images only after the corresponding workflow has been demonstrated. Use these filenames:

- `01-clone-repository.png`
- `02-python-environment.png`
- `03-tests-passing.png`
- `04-offline-drift-report.png`
- `05-live-baseline-scan.png`
- `06-minor-tag-drift.png`
- `07-critical-security-drift.png`

Before committing an image, remove or obscure AWS account IDs, resource IDs, public IP addresses, credentials, keys, and unrelated browser tabs.
